# Security reports

This is an experimental local capture viewer. GitHub private vulnerability reporting is enabled. Use [Report a vulnerability](https://github.com/gbaba86/usb-capture-viewer/security/advisories/new) for sensitive reports. There is no guaranteed response time.

Before opening a public issue, remove personal paths, device instance IDs, credentials, settings, logs and captured audio/video. A minimal written description without sensitive attachments is preferred. If a report cannot be made safely in public, use the private reporting link instead. Never include credentials even in a private report.

Do not send passwords, access tokens or API keys. Do not disable Windows protections to run a blocked binary. The current release is unsigned.

## ภาษาไทย

แอปนี้เป็นรุ่นทดลองสำหรับดูแคปเจอร์ในเครื่อง เปิด private vulnerability reporting ของ GitHub แล้ว ใช้ [Report a vulnerability](https://github.com/gbaba86/usb-capture-viewer/security/advisories/new) สำหรับเรื่องอ่อนไหว แต่ยังไม่รับประกันเวลาตอบ

ก่อนเปิด issue สาธารณะ ลบ path ส่วนตัว ตัวระบุอุปกรณ์ credential, settings, log และภาพ/เสียงแคปเจอร์ ควรใช้คำอธิบายสั้นที่ไม่มีข้อมูลอ่อนไหว หากแจ้งอย่างปลอดภัยในที่สาธารณะไม่ได้ ให้ใช้ลิงก์รายงานส่วนตัวแทน และอย่าใส่ credential แม้เป็นรายงานส่วนตัว

อย่าส่งรหัสผ่าน token หรือ API key และอย่าปิดการป้องกัน Windows เพื่อเปิดไบนารีที่ถูกบล็อก รุ่นปัจจุบันไม่ได้ลงนามดิจิทัล
