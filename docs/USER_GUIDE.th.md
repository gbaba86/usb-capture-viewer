# คู่มือใช้งาน — ภาษาไทย

[English](USER_GUIDE.en.md) · [หน้าแรก](../README.th.md) · [ดาวน์โหลด](https://github.com/gbaba86/usb-capture-viewer/releases/tag/v1.0.0-beta.1)

## 1. สิ่งที่ต้องมีและดาวน์โหลด

- คอม Windows x64, การ์ดแคปเจอร์ HDMI แบบ USB ที่เข้ากันได้, เครื่องเกม/ด็อกพร้อมไฟ, สาย HDMI และ USB
- ชุดที่ทดสอบจริงคือ Nintendo Switch 2 กับ AVerMedia Live Gamer MINI GC311 ยังไม่รับรองทุกการ์ด/เครื่องเกม แอปแสดงโหมด SDR ทั่วไปไม่เกิน 1080p60 ในพรีวิว 16:9
- ชุดพกพารวม .NET 10 และไลบรารีวิดีโอแล้ว ไม่ต้องติดตั้ง Python, .NET runtime, VLC หรือ OBS แยก
- ดาวน์โหลด `USB-Capture-Viewer-v1.0.0-beta.1-win-x64.zip` จาก Releases แตกไฟล์ **ทั้งหมด** ก่อนเปิด `SwitchCaptureViewer.exe` อย่าย้าย EXE ออกมาจาก DLL และโฟลเดอร์ย่อย
- รุ่นทดลองนี้ไม่ได้ลงนามดิจิทัล ตรวจ `SHA256SUMS.txt` และอย่าปิดระบบความปลอดภัยของ Windows หากถูกบล็อกอย่าข้ามการป้องกัน เว้นแต่คุณตรวจและเชื่อถือไฟล์ด้วยตนเอง

ตรวจไฟล์ใน PowerShell ได้ดังนี้:

```powershell
Get-FileHash .\USB-Capture-Viewer-v1.0.0-beta.1-win-x64.zip -Algorithm SHA256
```

เทียบผลกับบรรทัดชื่อไฟล์ใน `SHA256SUMS.txt` ของ Release เดียวกัน ค่า checksum ที่ตรงกันตรวจความครบของดาวน์โหลด ไม่ได้ยืนยันว่าซอฟต์แวร์ปลอดภัย

## 2. ต่ออุปกรณ์

1. จ่ายไฟให้เครื่องเกม/ด็อกตามคู่มือผู้ผลิต
2. ต่อ HDMI ออกจากเครื่องเกม/ด็อกเข้าช่อง **HDMI IN** ของการ์ด
3. ต่อ USB ของการ์ดเข้าคอม
4. HDMI OUT/pass-through เป็นทางเลือกตามการ์ด ไม่จำเป็นสำหรับพรีวิว GC311 ที่ทดสอบ
5. ปิดการใช้อุปกรณ์นี้ในโปรแกรมอื่น เช่น source แคปเจอร์ใน OBS แอปนี้ไม่ปิดโปรแกรมอื่นให้
6. อย่าให้เครื่องเกมพัก หากเห็นหน้าจับคู่จอยให้กดจอยของเครื่องเกมเพื่อเข้าเล่น คีย์บอร์ดคอมไม่ได้ควบคุมเกมผ่านแอปนี้

## 3. เปิดและเลือกอุปกรณ์

เปิด `SwitchCaptureViewer.exe` โปรแกรมจะเชื่อมต่ออุปกรณ์ที่จำไว้เอง ครั้งแรกหากพบ **Live Gamer MINI** จะเลือกภาพและ **Digital Audio Interface (Live Gamer MINI)** แล้วเชื่อมต่อให้อัตโนมัติ

การ์ดอื่นให้เลือก **อุปกรณ์วิดีโอ** และ **อุปกรณ์เสียงเข้า** ครั้งแรก เลือกเสียง HDMI ของการ์ด ซึ่งอาจชื่อไม่เหมือนวิดีโอ เลือก **ไม่รับเสียง** หากต้องการเฉพาะภาพ โปรแกรมจะจำค่า การเปลี่ยนอุปกรณ์จะเชื่อมต่อพรีวิวใหม่

หากระบุการ์ดไม่ได้แน่ชัด โปรแกรมจะรอให้เลือก ไม่เดาเปิดเว็บแคมหรือไมโครโฟนส่วนตัวเมื่อการ์ดที่จำไว้หายไป อุปกรณ์หลายตัวชื่อเหมือนกันยังเป็นข้อจำกัด ควรหลีกเลี่ยงการเสียบอุปกรณ์ชื่อซ้ำพร้อมกัน

## 4. เล่นและควบคุมหน้าต่าง

- **F11** หรือ **เต็มจอ**: เข้า/ออกเต็มจอ ซ่อนเมนู หัวแอปและแถบสถานะ
- **Esc**: ออกจากเต็มจอ ภาพเป็น 16:9 พร้อมขอบดำตามพื้นที่ ไม่ยืดตามทรงหน้าต่าง
- **ซ่อนเมนู / แสดงเมนู** มุมขวาบน: พับ/เปิดแถบควบคุม ใช้ **Tab** ได้เมื่อไม่ได้โฟกัสรายการอุปกรณ์
- แถบระดับเสียง: ปรับเสียงแอป **ปิดเสียง** หรือ **M** ปิด/เปิดเสียงเมื่อไม่ได้โฟกัสรายการอุปกรณ์
- เสียงออกอุปกรณ์เริ่มต้น Windows ที่เลือกตอนเปิด stream หากเปลี่ยนปลายทางเสียงให้กด **เชื่อมต่อใหม่**
- ปิดหน้าต่างเพื่อคืนอุปกรณ์ หากจะทับไฟล์รุ่นใหม่ ให้ปิดแอปจากโฟลเดอร์นั้นก่อน

## 5. ตั้งค่าการรับภาพเพิ่มเติม

เปิด **ตั้งค่าภาพ / เสียง** โปรแกรมจะพักการรับภาพระหว่างเปิดหน้าตั้งค่า และเชื่อมต่อเองเมื่อปิด กด **อ่านโหมดจากอุปกรณ์** เพื่ออ่านชนิดภาพที่ไดรเวอร์ของอุปกรณ์นั้นรายงาน การอ่านนี้ไม่สั่งให้ capture graph ทำงาน

เลือกความละเอียด FPS และ pixel format จากชุดที่เข้ากันได้ รายการเป็น SDR ทั่วไปไม่เกิน 1920×1080 ที่ 60 FPS รวมค่า FPS ปกติและปลายช่วงที่ไดรเวอร์ประกาศ ไม่ใช่ทุกค่าในช่วงต่อเนื่อง การที่ไดรเวอร์รายงานโหมดไม่ได้พิสูจน์ว่า HDMI จากเครื่องเกมรองรับโหมดนั้น

**กลับไปใช้ Auto** ให้ไดรเวอร์เจรจาโหมด ไม่รับประกันว่า Auto คือ 1080p60 กด **บันทึก** เพื่อจำค่า หรือ **ยกเลิก** หากไม่เปลี่ยน **เลือก 1080p/60 ถ้ามี** เลือกโหมดนี้เมื่อไดรเวอร์รายงานว่ามี

ค่าที่ทดสอบ GC311 คือ **1920×1080 / 60 / MJPG**, บัฟเฟอร์ภาพ **50 ms** ตัวเลือก 100/200 ms อาจช่วยเมื่อภาพสะดุดแต่เพิ่มดีเลย์ภาพ เสียงใช้ WASAPI shared แยกพร้อมคิวจำกัด ไม่ได้เพิ่มดีเลย์เสียงเพื่อตามภาพ

ค่าบัฟเฟอร์ภาพและบัฟเฟอร์เสียงที่ขอ **ไม่ใช่ latency รวมที่วัดได้** ยังมีความหน่วงจากการ์ด USB ไดรเวอร์ การถอดรหัส การแสดงผล ระบบเสียงและจอ ไม่รับประกัน zero latency และการใช้ CPU/GPU ไม่ใช่ผลวัดจากการกดจอยจนภาพปรากฏ

## 6. ค่าเริ่มต้นสำหรับ GC311 และ Switch 2

ตั้งบนเครื่องเกมเอง:

- System Settings → Display → TV Resolution: **1080p**
- 120 Hz Output: **Off** และ HDR Output: **Disabled / SDR**
- RGB Range: เริ่มที่ **Automatic**
- Audio → TV Sound: **Stereo**
- ดู Video Output Information ที่เครื่องเกมหากมี เพื่อยืนยันสัญญาณที่เจรจาได้

เป็นค่าเริ่มทดลองสำหรับชุดที่ทดสอบ GC311 ระบุรองรับสูงสุด 1080p60 ไม่รองรับ 4K, HDR หรือ refresh rate สูง ค่าการรับภาพ USB ในแอปคนละส่วนกับ HDMI ของเครื่องเกม แอปเปลี่ยนค่าเครื่องเกมโดยตรงไม่ได้

## 7. แก้ปัญหา

**ไม่พบอุปกรณ์:** ตรวจ USB/ไฟ และเลือกภาพ/เสียงที่ถูกต้อง โปรแกรมจะรออุปกรณ์ที่จำไว้ ใช้ **เชื่อมต่อใหม่** เพื่อลองอีกครั้ง แอปไม่ติดตั้งไดรเวอร์หรือเปลี่ยน Windows privacy settings ให้

**ภาพดำ/No Signal:** ตรวจ HDMI IN กับ OUT, ไฟด็อก, การพักเครื่องและสัญญาณ SDR ที่เข้ากันได้ หยุดโปรแกรมอื่นที่จับการ์ด ลอง Auto แล้วจึงลองโหมดต่ำลงที่ไดรเวอร์รายงาน เช่น 720p60 MJPG ฉากเกมดำไม่ใช่หลักฐานว่า HDMI หาย

**เสียงหาย/ขาด:** เลือกเสียง HDMI ของการ์ด ยกเลิกปิดเสียง เพิ่มระดับเสียงแอปและตรวจปลายทาง/volume mixer ของ Windows ตั้งเครื่องเกมเป็น Stereo เข้าเกมที่มีเสียงจริง หน้าจับคู่จอยอาจเงียบ เชื่อมต่อใหม่หลังเปลี่ยนปลายทางเสียง Windows ทางเสียงแยกจากบัฟเฟอร์ภาพ จึงไม่ใช้การเพิ่มบัฟเฟอร์ภาพเป็นวิธีแก้เสียง

**ยกออก/วางกลับด็อก:** รอการเจรจา HDMI เมื่อเฟรมหยุดหรืออุปกรณ์มี error โปรแกรมลองเชื่อมต่อใหม่แบบเว้นระยะ 3–60 วินาที ผู้ทดสอบยืนยันยก Switch 2 เข้าออกด็อกหลายรอบผ่านแล้ว หากการ์ดยังส่งเฟรมดำ/No Signal อาจต้องใช้ **เชื่อมต่อใหม่** แอปไม่รีสตาร์ตเพียงเพราะฉากเกมมืด ยังไม่รับรอง USB hotplug และอุปกรณ์ทุกชุด

**รู้สึกหน่วง:** เริ่มที่ MJPG กับบัฟเฟอร์ภาพ 50 ms ที่ทดสอบ หลีกเลี่ยงคิวยาว USB ที่ใช้งานหนักและแอปแคปเจอร์แข่งกัน การต่อ pass-through ไปจอแยกอาจมี latency ต่างจากพรีวิว USB ยังมีข้อจำกัดจากฮาร์ดแวร์ และยังไม่ได้วัด input-to-photon ที่แน่นอนสำหรับแอปนี้

## 8. ข้อมูลในเครื่องและการแจ้งปัญหา

ค่าที่จำไว้และ diagnostic แบบจำกัดขนาดอยู่ใน `%LOCALAPPDATA%\SwitchCaptureViewer` (`settings.json`, `viewer.log`, `capture-status.json` และไฟล์ inspect/self-test หากสั่งใช้) แอปไม่อัปโหลดข้อมูลเหล่านี้อัตโนมัติ

ไฟล์อาจมีชื่อ/ตัวระบุอุปกรณ์ path และรายละเอียด error ตรวจและลบข้อมูลส่วนตัวก่อนแชร์ อย่าใส่ภาพเกม เสียง ภาพหน้าจอส่วนตัวหรือ credential ใน issue ชุด public สร้างจาก staging ที่สะอาด ไม่รวมข้อมูลของผู้ทดสอบ shortcut Desktop หรือ debug symbols ดู [ความเป็นส่วนตัว](PRIVACY.md), [ผลทดสอบ](TESTING.md) และ [สิทธิ์ไลบรารี](../THIRD_PARTY_NOTICES.md)


ผลจากฮาร์ดแวร์อ้างอิง baseline ในเครื่องก่อนอัปเกรด ส่วนชุด public ที่ย้ายมา .NET 10 ตรวจซ้ำด้วยภาพ/เสียงสังเคราะห์ โดยไม่ได้เปิด capture ฮาร์ดแวร์รอบใหม่
